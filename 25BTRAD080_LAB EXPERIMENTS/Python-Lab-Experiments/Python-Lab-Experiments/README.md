# Python Lab Experiments (1–16)

This repository contains runnable Python source files prepared from the supplied lab experiment documents. Each experiment is kept in its own file and grouped into five parts.

## Folder structure

- `Part-1`: Experiments 1–4
- `Part-2`: Experiments 5–7
- `Part-3`: Experiments 8–10
- `Part-4`: Experiments 11–13
- `Part-5`: Experiments 14–16

## How to run

1. Install Python 3.
2. Download or clone this repository.
3. Open the required `Part-*` folder in VS Code or a terminal.
4. Run a program using `python Experiment_XX_Name.py`.
5. Follow the prompts shown in the terminal.

Some experiments use supporting files kept beside the Python program: `Part-4/sample.log`, `Part-4/employees.csv`. Experiment 12 creates `students.csv` when the first student record is added.

## Note about Experiment 1

The supplied Experiment 1 document is an installation and environment-setup exercise; it does not contain a standalone Python program. Its setup instructions are recorded in `Part-1/Experiment_01_README.md`. No source code has been invented for it.

## Source fidelity and small safeguards

The programs follow the operations and concepts in the supplied lab documents. Small input-validation and file-path safeguards have been added where useful so that the files are easier to run during demonstration. The core experiment logic and grading/payroll rules are retained.
